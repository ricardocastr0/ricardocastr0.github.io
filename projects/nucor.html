During my Nucor internship, I worked on vibration analysis software and a crane-orientation display attached to the main remote controller. I started with no steelmaking or industrial automation background and learned the process well enough to judge which automation solutions were feasible for day-to-day plant operation.

I developed a .NET application to flag abnormal vibration signatures on a hot mill roll stand, combining signal processing and regression modeling to catch developing mechanical issues before failure. The regression model was used to build in-house vibration sensing that established baseline behavior for a large input system.

I also modeled deflection, force loading, and stress distribution across a roll stand in SOLIDWORKS to validate structural performance under operating loads.

After being assigned a generalized safety project to help improve workers' procedures, I discovered the crane-orientation problem by talking directly with floor operators. They described repeated near-misses from bridging overhead cranes in the wrong direction when their body orientation did not match the crane's coordinate frame. I prototyped a display using an IMU, ESP32-S3, and LCD, mounted to the main remote controller with a modular attachment. It anchors to compass north and dynamically offsets the display based on the crane's forward-bridging direction.

Project images, test results, and deployment details are not included in this public overview.
